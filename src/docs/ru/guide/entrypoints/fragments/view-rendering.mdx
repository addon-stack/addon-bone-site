`render` задаёт содержимое страницы.
Addon Bone создаёт контейнер, помещает его в начало `document.body` и монтирует в нём результат.
Вам не нужно отдельно добавлять контейнер в документ или запускать рендерер фреймворка.

Функция `render` возвращает результат синхронно в обоих адаптерах.
Для загрузки данных верните начальное содержимое, затем обновите DOM в Vanilla или состояние компонента в React.

Способ отображения зависит от расширения файла:

| Файл | Способ отображения |
| --- | --- |
| `.ts`, `.js` | Vanilla: работа с DOM, строками и числами |
| `.tsx`, `.jsx` | React: компоненты, JSX и hooks |

Для обычного TypeScript используйте `.ts`; для React — `.tsx`.
Для JavaScript используйте `.js` с Vanilla или `.jsx` с React.
Сейчас встроены Vanilla и React.
