Подключайте собственные стили и модули через `import` в коде точки входа.
Addon Bone обработает TypeScript, JSX, CSS и SCSS и подключит к HTML файлы, которые нужны странице.

Соседние модули с компонентами и функциями становятся зависимостями этой точки входа.
Для другой самостоятельной страницы создайте отдельный файл точки входа; каждая страница получит собственный HTML.
Общие зависимости нескольких страниц сборщик может вынести в отдельные файлы — chunks.
Addon Bone добавит необходимые скрипты и таблицы стилей в HTML автоматически: перечислять chunks вручную не нужно.
