Addon Bone создаёт HTML и подключает скрипты точки входа вместе с её зависимостями.
Обычно этого достаточно: вы задаёте `title` и содержимое через `render`.

Для готовых ресурсов, которые подключаются отдельно от импортов, используйте `links` и `scripts`; для дополнительных метатегов — `metas`.
Строка в `links` или `scripts` задаёт путь к ресурсу, объект с `path` позволяет добавить `attributes`, а массив объединяет несколько записей.

Через `metas` добавьте сведения о странице, например её описание или поддерживаемые цветовые схемы.
Передайте объект с `attributes`: в нём задайте атрибуты метатега, например `name` и `content`.
Для нескольких метатегов используйте массив таких объектов.
Addon Bone добавит для каждого объекта отдельный `<meta>` в `<head>` сгенерированного HTML.
Каждая запись должна содержать непустой объект `attributes`.

`tags` объединяет ссылки и скрипты в одном списке: для обычных путей Addon Bone определяет вид тега по расширению `.css` или `.js`.
Используйте отдельные `links` и `scripts`, когда вид тега нужно указать явно, например для иконки.

Путь ресурса в этих настройках — путь в собранном расширении.
Положите готовые файлы в `src/public`, чтобы Addon Bone скопировал их в сборку.
Эти теги добавляют ссылки на готовые файлы; код и стили самой страницы подключайте через импорты, как показано выше.

Для собственной HTML-разметки задайте `template`: путь к шаблону разрешается относительно файла точки входа.
Скрипты сборки Addon Bone подключит сам.
Контейнер `render` добавляется в начало `body`; существующая разметка шаблона сохраняется.
