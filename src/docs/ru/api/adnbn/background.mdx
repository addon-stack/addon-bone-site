Примеры использования и жизненный цикл — в [руководстве Background](/guide/entrypoints/background).

| Экспорт | Вид | Назначение |

## `defineBackground`

<PropertyBadge text="function" type="info" outline />

Принимает объявление фоновой точки входа для `export default`.

```ts file="../../../../code/entrypoints/background/api/define-background.ts" title="defineBackground"
```

**Параметр:** `options` — [`BackgroundDefinition`](#backgrounddefinition). Аргумент обязателен; все его поля необязательны, поэтому допускается `defineBackground({})`.

**Результат:** [`BackgroundDefinition`](#backgrounddefinition) — исходный объект без копирования и подстановки значений по умолчанию. Вызов функции не запускает `main`.

## `BackgroundMainHandler`

<PropertyBadge text="type" type="info" outline />

Обработчик поля [`BackgroundDefinition.main`](#backgrounddefinition-main).

```ts file="../../../../code/entrypoints/background/api/background-main-handler.ts" title="BackgroundMainHandler"
```

**Параметр:** `options` — [`BackgroundOptions`](#backgroundoptions), опции текущего файла без `main`. Опции других файлов сюда не объединяются; отсутствующие поля не заполняются значениями по умолчанию.

**Результат:** `Awaiter<void>`, то есть `void | Promise<void>`. `Awaiter<T>` — вспомогательный тип `T | Promise<T>`; он не экспортируется из `adnbn`.

**Вызов:** при каждом запуске фонового контекста. Асинхронные обработчики разных фоновых файлов выполняются независимо.

Списки собранных файлов доступны в фоне через [`getEntrypointAssetsMap()`](/api/adnbn/entrypoint-assets#getentrypointassetsmap). Функция возвращает [`EntrypointAssetsMap`](/api/adnbn/entrypoint-assets#entrypointassetsmap); запись `background` содержит файлы общей фоновой сборки.

**Ошибка:** исключение или отклонённый promise выводится в фоновую консоль с сообщением `Failed to build entrypoint:`. Автоматического повтора нет.


<span id="backgroundconfig-permissions" />

Общие поля разрешений описаны в [`PermissionsOptions`](/api/adnbn/permissions#permissionsoptions).

<DocHeading level={3} id="backgroundconfig-persistent" toc={false}><code>persistent</code></DocHeading>

**Тип:** `boolean`. **Необязательное поле.** Управляет постоянной загрузкой фоновой страницы в Manifest V2.

Addon Bone объединяет значения всех включённых точек входа Background, Command и Service в одно поле `background.persistent`:

| Значения в точках входа | Результат в Manifest V2 |
| --- | --- |
| Хотя бы одно `true` | `persistent: true`. Фоновая страница остаётся загруженной. |
| Есть `false`, нет `true` | `persistent: false`. Браузер может выгрузить фоновую страницу при простое и загрузить при событии. |
| Опция нигде не задана | Поле отсутствует. Браузер использует `true` по умолчанию. |

В Manifest V3 Addon Bone не записывает это поле независимо от значения опции.

Значения поля манифеста — в [справочнике MDN](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/manifest.json/background).
